# Face detection fixture

`face-public-domain.png` is the NASA astronaut photograph distributed by scikit-image 0.19.3, downloaded from:
https://raw.githubusercontent.com/scikit-image/scikit-image/v0.19.3/skimage/data/astronaut.png

Provenance and public-domain notice: https://scikit-image.org/docs/stable/api/skimage.data.html#skimage.data.astronaut
This is a test-only, publicly released image, not a user image or a product endorsement. The tests assert an approximate face count. They never assign or persist a person's identity. No face crop or biometric embedding is retained. Other fixtures are non-personal deterministic graphics generated by `analysis/fixtures.py` outside Git.

Local detector: OpenCV Haar frontal-face cascade distributed with the pinned `opencv-python-headless` wheel. OpenCV: https://docs.opencv.org/4.13.0/db/d28/tutorial_cascade_classifier.html . Licenses are included in the wheel; no model is downloaded at runtime.
