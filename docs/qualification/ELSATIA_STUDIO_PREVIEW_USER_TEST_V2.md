# ELSATIA Studio — Guide de test utilisateur Preview (V2)

> **État au 2026-09-30 : lien non encore disponible (STUDIO PREVIEW BLOCKED).**
> Ce guide s'appliquera dès que `https://studio-preview.elsatia.fr` (ou l'URL Vercel stable
> indiquée dans `ELSATIA_STUDIO_PREVIEW_DEPLOYMENT_V2.md`) sera en ligne.

Durée : ~15 minutes. Utilisez un compte ELSATIA de **test** autorisé (allowlist Preview).
Aucun vrai client, aucune donnée réelle.

1. **Connexion** — Ouvrir l'URL, cliquer « Continuer avec mon compte ELSATIA », se connecter sur
   ELSATIA, revenir automatiquement dans Studio (tableau de bord). Il n'y a pas d'inscription ni de
   mot de passe Studio : c'est normal.
2. **Créer un espace** — Suivre l'onboarding, nommer l'espace de travail.
3. **Créer un projet** — « Nouveau projet », lui donner un nom, l'ouvrir.
4. **Importer un média** — Ajouter une photo ou une courte vidéo de test ; vérifier l'aperçu.
5. **Lancer un rendu** (si disponible) — Exporter ; si le message « rendu indisponible » apparaît,
   c'est attendu tant que le worker Preview n'est pas déployé.
6. **Partager un lien** — Créer un lien public, l'ouvrir en navigation privée, puis le révoquer et
   vérifier qu'il ne fonctionne plus. Inviter un membre : copier le lien d'invitation affiché.
7. **Tester sur mobile** — Refaire 1 et 4 sur iPhone (Safari) ou Android, et sur tablette.
8. **Déconnexion** — Menu → « Se déconnecter » ; revenir sur l'URL : la connexion est redemandée.

À signaler : capture d'écran, heure, appareil/navigateur, étape.
