1. Comment lire ce guide

Skill, plugin, connecteur, logiciel

  • Skill : mode d'emploi (SKILL.md) que Claude charge pour une tâche. Appel manuel : /nom.
  • Plugin : paquet pouvant contenir des skills, agents, hooks ou un connecteur. Ses skills s'appellent /plugin:skill.
  • Connecteur MCP : accès à un service extérieur (documentation, GitHub). Ce n'est pas un skill.
  • Logiciel associé : programme installé sur la machine (Playwright, ffmpeg, yt-dlp, Remotion, WhisperX).

Mode de déclenchement vérifié

  • Auto observé + manuel : Claude a effectivement chargé le skill seul pendant un essai (appel de l'outil Skill constaté dans le journal).
  • Auto possible (non observé) + manuel : la configuration le permet, mais Claude a répondu sans le charger lors de l'essai. Ce n'est pas un skill manuel.
  • Auto possible (non testé) + manuel : la configuration le permet ; aucun essai de sélection automatique n'a été fait.
  • Manuel uniquement : prouvé par la configuration (disable-model-invocation: true) et par le refus de l'outil Skill.
  • Non confirmé : comportement qui n'a pas pu être établi.
La sélection automatique n'est jamais garantie : elle dépend de la formulation, de la configuration et de la session. Pour être sûr d'utiliser un skill, tapez sa commande. Tous les skills « auto » acceptent aussi l'appel manuel.

Disponibilité

  • PR #6 seulement : présent sur la branche claude/stoic-shannon-9ax0mp, pas encore sur main.
  • main : déjà fusionné dans main (PR #5), donc aussi présent sur la branche.
  • Hors dépôt : fourni par Claude Code ou par le compte claude.ai, indépendamment du dépôt.
