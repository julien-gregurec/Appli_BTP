# C5-E2 — Validation manuelle du lot pilote ELSATIA avant contact

## 1. Objet, date et garde-fous

Seconde qualification réalisée le **16 août 2026** sur les dix entreprises du lot 1 C5-E. Le travail couvre uniquement la vérification publique, le scoring, le choix du décideur cible, du canal, de l’angle d’approche et de l’offre potentielle.

**Aucun contact n’a été effectué.** Aucun e-mail, appel, SMS, message LinkedIn, formulaire ou essai ELSATIA n’a été déclenché. Les onglets `ACTIONS` et `OPPOSITIONS` du classeur privé sont vides. Les dix fiches restent au statut `Qualifié`.

## 2. Méthode

Pour chaque société, la vérification a combiné :

1. l’API Recherche d’entreprises de l’État pour le statut actif, la raison sociale, le siège, l’activité, l’effectif public et les dirigeants déclarés ;
2. le site officiel lorsqu’il existe, pour les métiers, l’organisation, les équipes, les réalisations et les coordonnées professionnelles ;
3. une source professionnelle secondaire lorsque nécessaire : Qualibat, BOAMP, PagesJaunes, annuaire RGE ou registre professionnel public ;
4. la grille C5-A inchangée, avec `?` pour les critères non établis ;
5. la liste d’opposition avant tout verdict `GO`.

Les critères `C6_DISPERSION_OUTILS` et `C7_PILOTAGE_RENTABILITE` restent inconnus pour les dix sociétés. Aucun usage d’Excel, WhatsApp ou autre logiciel, aucune double saisie et aucune difficulté de rentabilité ne sont supposés.
